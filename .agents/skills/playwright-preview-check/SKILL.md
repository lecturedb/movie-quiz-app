# Playwright Preview Check

## 사용 시점

화면이나 사용자 흐름이 변경된 작업이 끝난 뒤 사용한다.

## 확인 절차

1. 프로젝트에 맞는 개발 서버 또는 정적 서버를 실행한다.
2. Playwright 브라우저로 앱을 연다.
3. 주요 화면의 레이아웃과 콘텐츠가 깨지지 않는지 확인한다.
4. 핵심 버튼이나 입력 동작이 있으면 대표 흐름을 간단히 확인한다.
5. 브라우저 콘솔 오류를 확인한다.
6. 데스크톱과 모바일 뷰포트에서 각각 스크린샷을 저장한다.

## 결과물

- 프로젝트 루트의 `screenshots/` 폴더에 스크린샷을 저장한다.
- 확인한 화면, 동작, 콘솔 오류 여부를 간단히 요약한다.

## 주의사항

- 확인 과정에서 앱 코드를 수정하지 않는다.
- 실패한 항목을 숨기지 말고 증상과 가능한 원인을 함께 보고한다.
